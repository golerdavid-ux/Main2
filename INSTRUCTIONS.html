🧾 Invoice Generator - Setup Instructions

Your invoice generator has been created successfully! Here's how to run and test it:

⚠️ Important: This application requires Node.js to be installed on your local machine.

Step 1: Download the Code

Download the entire Main2 folder from your Claude Code workspace to your local computer.

Step 2: Install Backend Dependencies

Open a terminal/command prompt and run:

cd path/to/Main2/backend
npm install

Step 3: Configure Email Settings

Edit backend/.env with your email credentials:

  • For Gmail: Use an App Password (not your regular password)
  • Update your business information

Step 4: Start the Backend Server

cd backend
npm start

Should show: "Invoice Generator API running on port 3001"

Step 5: Install Frontend Dependencies

Open a NEW terminal/command prompt and run:

cd path/to/Main2/frontend
npm install

Step 6: Start the Frontend

npm start

Your browser should automatically open to http://localhost:3000

Step 7: Test the Invoice Generator

  1. Fill in customer information
  2. Select a product from the dropdown
  3. Click "Preview PDF" to test without sending email
  4. Click "Generate & Email Invoice" to send the invoice
